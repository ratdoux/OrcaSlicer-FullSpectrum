Mixed Filament Refactor Map

Typed definition first, compatibility DTO at the edge.

What changed?

Mixed filament state now has a readable domain object: MixedFilamentDefinition. The old flat row still exists as MixedFilamentLegacyRow, but only as a derived compatibility DTO rather than the manager's source of truth.

weighted blends manual pattern groups visibility tombstones legacy adapters vNext bridge

Rule of thumb

If code is about UI, package import/export, display, slicing intent, or feature behavior, use MixedFilamentDefinition. Only old project-config and legacy/compat 3MF boundaries should cross through MixedFilamentLegacyRow. There is no generic MixedFilament alias anymore.

One blend shape

Two-filament pair blends and 3+ multi-color blends both use weighted physical components.

Patterns stay exact

Manual and multi-perimeter recipes keep their grouped sequence instead of being collapsed into percentages.

Compatibility contained

Flat row tokens, gradient strings, and A/B token conversion sit behind explicit DTO adapters.

Manager owns definitions

MixedFilamentManager stores typed definitions. Legacy DTO rows are snapshots rebuilt on demand.

Before

The old compatibility DTO mixes identity, source, lifecycle, recipe, behavior, and display into one flat shape.

struct MixedFilamentLegacyRow {
    unsigned int component_a;
    unsigned int component_b;
    uint64_t stable_id;
    int ratio_a;
    int ratio_b;
    int mix_b_percent;
    std::string manual_pattern;
    std::string gradient_component_ids;
    std::string gradient_component_weights;
    int distribution_mode;
    int local_z_max_sublayers;
    bool enabled;  // legacy only now
    bool deleted;
    bool custom;
    bool origin_auto;
};

After

The typed model groups state by meaning. The manager owns this shape directly.

struct MixedFilamentDefinition {
    MixedFilamentIdentity     identity;
    MixedFilamentSource       source;
    MixedFilamentVisibility   visibility;
    MixedFilamentRecipe       recipe;
    MixedFilamentBehavior     behavior;
    MixedFilamentPresentation presentation;
};

Recipe

struct MixedFilamentWeightedBlend {
    std::vector<MixedFilamentWeightedComponent> components;
    std::optional<MixedFilamentPrimaryPairView> primary_pair() const;
    MixedFilamentPrimaryPairView primary_pair_or(...) const;
    std::vector<unsigned int> component_ids(size_t num_physical = 0) const;
    std::vector<int> component_percents(size_t num_physical = 0) const;
};

struct MixedFilamentRecipe {
    MixedFilamentWeightedBlend blend;
    std::optional<MixedFilamentManualPattern> manual_pattern;
    MixedFilamentRecipeKind kind;
};

Behavior

struct MixedFilamentBehavior {
    MixedFilamentDistributionMode distribution;
    MixedFilamentLayerCadence     layer_cadence;
    MixedFilamentLocalZBehavior   local_z;
    MixedFilamentSurfaceBias      surface_bias;
};

Data Boundaries

MixedFilamentDefinition is the canonical in-memory object. Legacy rows and package JSON are edge formats translated into and out of it.

Compatibility DTO

Import/export adapter for mixed_filament_definitions, compact A/B fields, pattern tokens, gradient strings, and deleted tombstones.

<->

MixedFilamentDefinition

Identity, source, visibility, recipe, behavior, and presentation as typed C++ fields. This is the manager-owned source of truth.

<->

vNext package model

Import/export adapter for VirtualFilament with stable refs, visibility state, origin, blend, gradient, pattern, and Local-Z.

DTO adapters

Definition.cpp, LegacyRow.cpp, Pattern.cpp, and Gradient.cpp.

Runtime

Resolver.cpp maps virtual IDs back to physical filament IDs for layers and perimeters.

Presentation

Display.cpp and Preview.cpp compute preview color and UI sequences.

Examples

definition.recipe.kind = MixedFilamentRecipeKind::WeightedBlend;
definition.recipe.blend.components = {
    { {1}, 35 },
    { {2}, 65 }
};
definition.behavior.distribution = MixedFilamentDistributionMode::Simple;

The legacy row writes A/B plus mix_b_percent. No gradient strings are needed.

definition.recipe.kind = MixedFilamentRecipeKind::WeightedBlend;
definition.recipe.blend.components = {
    { {1}, 50 },
    { {2}, 25 },
    { {3}, 25 }
};
definition.behavior.distribution = MixedFilamentDistributionMode::LayerCycle;

The legacy row projects this to gradient_component_ids and weights. vNext writes the explicit component set as canonical gradient data.

definition.recipe.kind = MixedFilamentRecipeKind::ManualPattern;
definition.recipe.manual_pattern = MixedFilamentManualPattern{
    {
        { {1}, {1}, {1}, {2} },
        { {2}, {1}, {1}, {1} }
    }
};
definition.recipe.blend.components = {
    { {1}, 75 },
    { {2}, 25 }
};

The blend is the summary; the grouped pattern is the exact perimeter sequence.

definition.visibility.tombstoned = true;

This maps to legacy deleted and vNext visibility_state: "tombstoned". The old enabled bit is legacy-only.

Glossary

MixedFilamentDefinition
The typed decoded object. Use this for UI, package code, display logic, and feature behavior.
MixedFilamentLegacyRow
The explicit DTO used by existing project settings and legacy 3MF projections. It is derived from the typed definition; the old MixedFilament alias has been removed.
MixedFilamentWeightedBlend
A weighted list of physical filament refs. Use component_ids(...) and component_percents(...) for aligned component arrays; primary_pair() is only the A/B projection.
MixedFilamentManualPattern
Exact grouped sequence for manual and multi-perimeter patterns. It is not replaced by percentages.
visibility.tombstoned
The meaningful hidden/deleted state. It preserves deleted auto rows so regeneration does not resurrect them.
enabled
A legacy column. Runtime treats every non-tombstoned row as available.
Primary A/B pair
The first two blend components are the deterministic pair used by legacy tokens, Local-Z pair splitting, surface bias, and vNext origin refs. Importers and manual-pattern summaries normalize component order around this pair, then append extra weighted components.
Legacy pair adapter
The old public pair helper is now private to mixed filament internals because it only exists to translate compact legacy tokens.
Legacy weighted fields
The old g123 and w50/25/25 fields are compatibility encodings for 3+ weighted blend components.
